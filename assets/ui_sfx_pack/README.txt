IRIS UI SFX Pack

Drop your licensed/free UI sound files here to override default app sounds.
Preferred filenames (ogg/wav accepted for most):
- nav_soft.ogg or nav_soft.wav
- nav_click.ogg or nav_click.wav
- confirm.ogg or confirm.wav
- toggle_soft.ogg or toggle_soft.wav
- laser.ogg or laser.wav
- coins.ogg or coins.wav
- mission.ogg or mission.mp3

Pro variant mode (recommended):
- nav_soft_1.ogg, nav_soft_2.ogg, nav_soft_3.ogg
- nav_click_1.ogg, nav_click_2.ogg, nav_click_3.ogg
- confirm_1.ogg, confirm_2.ogg
- toggle_soft_1.ogg, toggle_soft_2.ogg

The app randomly picks from available numbered variants for a more premium, less repetitive feel.

Notes:
- Keep files short (50-300 ms for taps/clicks, up to 700 ms for confirm).
- Normalize peaks around -3 dB to avoid clipping.
- Target loudness around -16 to -20 LUFS short-term for clean UI balance.
- Prefer 48kHz assets with tight transient design (digital/UI style).
- Use only assets with valid free/commercial licenses for your project.
